Research Projects

1. Multi-Variate Time Series Anomaly Detection
Aug 2021 – Present
Exploring unsupervised methods for anomaly detection in multivariate time-series from cyber-physical systems:
  • HEIGHTS — Hierarchical Graph Structure Learning using two-level multi-view learning. Published in Neurocomputing 2026.
  • FILTER — Nonparametric Feature Clustering for automatic feature grouping and explainable anomaly detection. Under review.
  • ProtoAD — Explainable anomaly detection via prototypes representing normal system behaviour.
2. Fast Radio Burst (FRB) Identification in Astronomical Time Series
Nov 2022 – Jan 2024
Collaboration with NCRA Pune, NVIDIA, and IIT Palakkad (NVAITC Program)
Developed a multi-beam AI classifier to detect FRBs. Contributed to the SPOTLIGHT system deployed at GMRT, NCRA, Pune.
3. TCAV — Testing with Concept Activation Vectors
April 2022
Applied TCAV (Google) to a fruit classifier (GoogleNet on Fruits360) to identify human-friendly concepts. (CS6006: Responsible AI, IIT Palakkad)
4. Image Captioning with CNN-LSTM
April 2022
Deep learning framework for automatic image caption generation evaluated using BLEU score. (CS5007: Deep Learning, IIT Palakkad)
5. Automatic Summarization using Semantic WordClouds
May 2018 – July 2019
M.Tech Thesis · Published at NetCom 2021, Springer
Novel semantic word cloud methodology using K-Medoids clustering on co-occurrence similarity matrices, evaluated using "Realized Adjacencies" metric.
